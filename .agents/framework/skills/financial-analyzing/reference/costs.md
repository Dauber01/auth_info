# Cost Analysis Reference

Use the same currency, reporting period, and accounting scope for each comparison.
Distinguish cost of goods sold (COGS) from operating expenses to avoid double counting.

| Metric | Formula | Required context |
| --- | --- | --- |
| COGS ratio | COGS / revenue × 100% | Revenue must be nonzero |
| Operating expense ratio | Operating expenses / revenue × 100% | State included expense categories |
| Cost change | Current cost − previous cost | Comparable periods and categories |
| Cost growth | (Current cost − previous cost) / previous cost × 100% | Percentage change is undefined at zero prior cost |
| Unit cost | Relevant total cost / units produced | Specify volume and allocation basis |

Break down movements into volume, unit price, mix, and one-off items when the
provided data permits it. Separate fixed and variable costs where meaningful.
Do not infer that every cost increase is undesirable: compare it with changes
in revenue, output, quality, and capacity. Use current, attributable benchmarks
when the task needs an industry comparison; do not invent a universal target.
