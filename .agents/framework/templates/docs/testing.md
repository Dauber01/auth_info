# 测试约定

项目测试命令与环境前提尚待采集。根 tests/api 使用 Python 调用 API；单元测试遵循
项目已有语言约定；页面用例在各任务 ui-cases.json 中，由具备浏览器能力的 agent 执行。

每轮代码修改后执行 generate-tests，根据 PRD、契约和实际 diff 生成/更新用例。
记录 Case ID、需求、前置条件、输入、操作、预期、清理、自动化位置与验证结果。
优先使用隔离测试服务或可重置数据；不把真实账号/Token 写进用例或提交记录。

本模板没有 runnable API 用例。接入项目后先建立真实测试入口，不能将空目录检查当作 API 通过。
